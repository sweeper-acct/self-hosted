# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Sweeper Self-Hosted, please report it
by email to:

**service@sweeper-acct.com.au**

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Your contact details (optional)

We aim to respond within 48 hours and will keep you informed as we investigate
and address the issue.

Please do not disclose security vulnerabilities publicly until we have had the
opportunity to investigate and issue a fix.

## Supported Versions

Only the latest released version of Sweeper Self-Hosted receives security updates.
We recommend keeping your deployment up to date.
