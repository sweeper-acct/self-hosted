# Contributing

Sweeper Self-Hosted is a commercial product. We do not accept code contributions at this time.

## Bug Reports

Found a bug? Email us at **service@sweeper-acct.com.au** with:
- Steps to reproduce
- Expected vs actual behaviour
- Your Sweeper version (`SWEEPER_VERSION` in your `.env`)

## Feature Requests

Have a suggestion? Email **service@sweeper-acct.com.au** with a brief description of the use case.

## Security Vulnerabilities

Please do not report security issues publicly. See [SECURITY.md](SECURITY.md) for responsible disclosure guidelines.
